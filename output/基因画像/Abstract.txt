# 《基因画像》创作构思文档

---

## 模块1：故事元信息

- **故事名称**：《基因画像》
- **故事类型**：都市悬疑/商战复仇
- **故事主题（一句话概括）**：被拐家庭的幸存者化身基因科学家，用技术复仇，揭露人口贩卖黑产的真相。
- **核心矛盾（一句话概括）**：女主表面为黑心机构研发基因检测技术，实则在每一份报告中埋下翻案的“指纹”；男主是当年案件的受害者家属，如今成为科技新贵，在爱恨交织中与女主博弈。
- **时代背景**：2023-2025年（近未来）
- **故事总长度预估**：约 80 章 / 40 万字

## 模块5：章节/部分大纲（事件链格式）

### 第一部分：暗流（第1-20章）——痛点引入与关系建立

**故事开端（第1-5章）**：

- **第1章结尾钩子**：明德基因发布会上，CEO陆明远宣布“儿童基因数据库”即将上线，声称“让每一个失踪儿童都能回家”。顾深站在台下，手指死死掐进掌心。

- **第2章**：
  1. 顾深回到实验室，深夜独自检测新入库的DNA样本
  2. 屏幕跳出匹配提示：样本#7942与2012年拐卖案DNA吻合
  3. 苏棠（助手）突然返回实验室拿钥匙，撞见顾深在操作
  4. 顾深迅速关闭界面，谎称在调试设备
  5. 苏棠离开后，顾深将数据存入个人密钥U盘
  6. **顾深内心独白**：“这是第23个。还差57个，数据库就完整了。”

- **第3章**：
  1. 陆明远召集核心团队，宣布“基因画像”项目获得政府试点资格
  2. 顾深被任命为项目技术总负责，赵博士被架空
  3. 会后，陆明远单独留下顾深，暗示要“筛选”某些样本
  4. 顾深表面接受，内心警惕
  5. 周牧（法务总监）交给顾深一份“保密协议”
  6. 顾深回到工位，发现电脑曾被远程访问

- **第4章**：
  1. 顾深回到出租屋，翻出少管所的入狱照
  2. 闪回：2012年，17岁的顾深试图救姐姐失败
  3. 闪回：2014年出狱，父亲在病床上说“你姐姐还在等我”
  4. 顾深在日记本上写下：“第7942号：确认，送达。”
  5. 她打开笔记本电脑，查看“姐姐”文件夹——已故/被确认死亡的被拐儿童档案
  6. 顾浅的照片在文件夹第一页，标注：2012.6.15-2012.9（推定死亡）

- **第5章**：
  1. 归航科技CEO沈寒舟主动拜访明德基因，寻求合作
  2. 沈寒舟在会议室展示妹妹沈雨桐失踪12年的寻人启事
  3. 顾深首次见到沈寒舟，注意到他眼神中的执念（与自己相似）
  4. 陆明远热情接待，允诺合作
  5. 沈寒舟与顾深握手时，注意到她手腕内侧的疤痕（少管所时期遗留）
  6. 沈寒舟离开后，顾深查询沈雨桐失踪案——发现与顾浅同案

**前期铺垫（第6-15章）**：

- **第6章**：
  1. 沈寒舟二次来访，单独约顾深喝咖啡
  2. 沈寒舟出示琥珀吊坠，说是方律师（父亲朋友）交给他
  3. 顾深看到吊坠瞳孔骤缩——她认出了
  4. 沈寒舟察觉异常，追问顾深
  5. 顾深谎称“只是觉得好看”
  6. 沈寒舟邀请顾深参观归航科技
  7. 顾深犹豫后答应

- **第7章**：
  1. 归航科技的展厅展示失踪儿童数据，沈寒舟介绍平台运作机制
  2. 顾深看到一面墙——被成功找回的孩子照片
  3. 沈寒舟语调低沉：“我们找回了127个孩子，但还有三千多个没回来”
  4. 顾深问：“你妹妹找到了吗”
  5. 沈寒舟沉默摇头
  6. 顾深内心：“她的妹妹和我的姐姐，在同一辆车里”
  7. 两人关系首次建立情感连接

- **第8章**：
  1. 顾深回到实验室，秘密创建个人DNA匹配数据库
  2. 她将明德基因数据库中涉嫌非法获取的样本逐一复制
  3. 苏棠敲门送宵夜，顾深险些暴露
  4. 顾深意识到实验室有监控，开始暗中寻找死角
  5. 苏棠问：“深姐，你为什么总是加班到这么晚”
  6. 顾深答：“为了不让别人再失去家人”
  7. 苏棠若有所思，之后开始主动掩护顾深

- **第9章**：
  1. 陆明远安排顾深参加“内部宴会”，实际是政府游说酒会
  2. 顾深在酒会上听到周牧与某官员谈论“数据库筛选标准”
  3. 顾深用手机录音，但被周牧助手发现
  4. 顾深谎称“只是看信息”，被要求交出手机
  5. 陆明远出面解围，但眼神警告顾深
  6. 顾深回家后检查手机，发现被植入追踪软件
  7. 顾深决定重新使用旧手机（少管所时期的老款）

- **第10章**：
  1. 苏棠发现顾深在偷偷备份数据，主动提出帮忙
  2. 顾深拒绝，苏棠说出自己孤儿院出身
  3. 苏棠：“我不知道自己是谁，所以我不想别人也这样”
  4. 顾深松口，让苏棠负责监控实验室的安保轮班
  5. 苏棠制作轮班表，标记出每周唯一的“盲区时段”
  6. 两人正式建立战线

- **第11章**：
  1. 沈寒舟第三次来访，带来方律师整理的2012年案件资料
  2. 资料显示顾浅和沈雨桐被同一辆车转运
  3. 沈寒舟问顾深：“你认识顾浅吗？”
  4. 顾深沉默数秒：“她是我的姐姐”
  5. 沈寒舟震惊
  6. 顾深：“所以我知道，这个数据库对你们意味着什么”

- **第12章**：
  1. 顾深首次向沈寒舟透露明德基因的“筛选”内幕
  2. 沈寒舟愤怒，质问顾深“为什么还在为他们工作”
  3. 顾深：“因为没有内部人，就永远找不到证据”
  4. 沈寒舟沉默
  5. 顾深提议合作：她提供数据证据，沈寒舟提供公众影响力
  6. 沈寒舟同意，但要求“不以伤害无辜为代价”

- **第13章**：
  1. 苏棠无意中看到顾深书桌上的姐姐画像
  2. 苏棠：“这是你姐姐？”
  3. 顾深：“她叫顾浅，19岁失踪，后来……没回来”
  4. 苏棠落泪，抱住了顾深
  5. 顾深第一次在他人面前流泪
  6. 两人关系从上下级变为真正的情感链接

- **第14章**：
  1. 项目进入测试阶段，陆明远要求顾深“优化算法”
  2. 顾深理解“优化”含义：筛除某些“不必要”的样本
  3. 顾深拒绝，陆明远威逼利诱
  4. 顾深提出“算法需要时间调试”，拖延
  5. 周牧暗示顾深“别忘了保密协议”
  6. 顾深将陆明远的谈话录音备份

- **第15章**：
  1. 沈寒舟通过方律师联系到2012年案件的另一名受害者家属
  2. 家属提供当年转运窝点的地址
  3. 沈寒舟将地址交给顾深
  4. 顾深查询该地址附近医疗记录——发现与明德基因早期资助的诊所重合
  5. 顾深开始调查明德基因的“前身”
  6. 发现陆明远1998-2005年间投资多家妇产/儿科诊所

### 第二部分：博弈（第21-40章）——危机升级与信任加深

**中期推进（第21-30章）**：

- **第21章**：
  1. 苏棠的黑客操作被发现（利用第18章铺垫）
  2. 明德基因的IT部门锁定苏棠的IP
  3. 陆明远召见苏棠，苏棠谎称“在测试新算法接口”
  4. 陆明远要求苏棠交出电脑检查
  5. 顾深抢在检查前，远程删除苏棠电脑中的敏感文件
  6. 检查未发现异常，但陆明远加强了对苏棠的监控
  7. 顾深意识到：时间不多了
